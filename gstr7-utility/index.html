Free GSTR-7 offline return preparation for tax deductors

GSTR-7 is the monthly return that a person who deducts tax at source under GST files on the GST portal. This free tool helps you prepare Table 3 (tax deducted) and Table 4 (amendments), check every row, and create the JSON file for upload, without installing a spreadsheet macro. It runs in your browser and your data stays on your device.

Who it is for

Government departments, local bodies, public sector undertakings and others who deduct tax at source, and the accountants who prepare their returns.

1. Purpose

  • This tool helps a tax deductor (a person who deducts tax at source under section 51 of the CGST Act) prepare the monthly GSTR-7 return offline. It checks the data and creates the JSON file that is uploaded on the GST portal. It does not file the return. You must upload the file on the portal, preview the form and file it there.

2. Before you start

  • Keep the GSTIN of the deductor (the 14th character is D), and the list of deductees with the amount paid and the tax deducted for the month. From September 2025 the portal asks for the invoice or document number, date and value of every payment.

3. Steps

  1. Home: enter the GSTIN, the financial year and the tax period. Choose Save at the top (or press Ctrl+S) and pick a save location in Chrome or Edge, so that every change is saved to your own file.
  2. Suppliers master (optional): add the GSTIN, legal name and trade name of your regular deductees (use the Excel template to upload many at once, and the search box to find a supplier). A GSTIN entered twice gives a warning [G7-E402]; keep one row for it. The names then fill in by themselves.
  3. Table 3: add one row for each document (or, for periods before September 2025, one row for each deductee). Type, paste from Excel, or import a CSV or Excel file.
  4. Table 4: add rows only for amendments to earlier periods. The amended month must be earlier than the return period.
  5. Validate each table. Cells in red show the problem and its error code. Fix them and validate again.
  6. Home: choose Validate all and get summary, then Generate JSON file to upload.
  7. On the GST portal open Returns Dashboard, choose the period, GSTR-7, Prepare Offline, and upload the JSON file. Preview, then file.

4. How the main checks work

  • Action: Add creates or revises a record; Delete removes a record already on the portal.
  • Tax: enter either Integrated tax, or CGST and SGST (which must be equal). Total tax cannot exceed the amount paid. As in the official utility, the tax is typed by you; the tool does not work it out.
  • Dates are typed as DD/MM/YYYY and cannot be before 1 July 2017 or after the end of the period.
  • Periods before September 2025 use the earlier format: no document details, one row for each GSTIN and action, IGST only for another State, CGST and SGST only within the State.
  • In Table 4, for September 2025 either fill all six document fields or leave all six blank. For periods before September 2025 the document fields are not needed. From October 2025 they are required.
  • Records rejected by deductee: choose Yes when the deductee rejected the record on the portal.

5. If the portal shows errors

  • Download the error report (returns__R7__errorReport.json). Choose Open downloaded error JSON file on the Home screen. Correct the rows, using the portal message in the last column, then generate and upload the JSON again.

6. Limits

  • Up to 10,000 rows in each table. Up to 5,000 records in each upload file; larger returns are split automatically.
  • The tool is based on the offline utility version 4.1 as published for FY 2026-27. The portal may change its rules; the portal is always the final check.
  • The Excel import and export need an internet connection to load the spreadsheet reader once. CSV works offline.
  • Your data is stored only in this browser. Download a backup regularly.

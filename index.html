FAQs

Frequently asked questions

Quick answers about the tools.

Are these payroll compliance tools free?

Yes. All tools are free to use, with no sign-up. A voluntary donation is welcome but creates no warranty, support or service obligation.

Is my employee data uploaded to a server?

No. The tools run in your browser. Data stays on your device. In Chrome or Edge you can choose a file on your computer where the tool saves your work automatically, and every tool can download and restore a backup file.

Which browser should I use?

Any modern browser works. For automatic saving to a file you choose, use Chrome or Edge on a computer. Other browsers keep data in browser storage and use backup download and upload.

Are these official EPFO or ESIC tools?

No. They are independent working aids from Techmin HR Solutions. Always verify figures, eligibility and file formats against current EPFO and ESIC instructions before filing.

Can I get help with payroll, EPF and ESI compliance?

Yes. Techmin HR Solutions, a subsidiary of Techmin Wealth Partners, supports payroll management, EPF, ESI and labour compliance for employers in Kerala. Use the contact details on this page or visit the ComplyPro website.

Does every tool have a user guide?

Yes. Each tool has release notes and a user guide inside the tool and as a downloadable PDF, covering purpose, how to use it, how figures are worked out, privacy and limits.

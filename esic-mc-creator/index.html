Release notes and user guide

ESIC Monthly Contribution Creator, Version 1.0.0, released 24 October 2026.

1. Purpose

ESIC Monthly Contribution Creator helps an employer prepare the monthly ESIC contribution data for review. It calculates the employee and employer shares for every insured person, checks each row, and produces an Excel file arranged like the common ESIC monthly contribution file structure. Your work is saved, so it is still there the next time you open the tool.

  • Prepare the monthly ESIC contribution sheet quickly from a simple input template.
  • See the employee share (0.75 per cent) and employer share (3.25 per cent) for each person and in total, rounded upward to the next rupee.
  • Apply the Rs. 176 average daily wage exemption for the employee share, with a warning to confirm the prescribed calculation.
  • Catch wrong IP numbers, missing names, wrong days and wages, and wrong status or last working day combinations before filing.
  • Keep the rows, wage month and establishment name saved, with a backup you can download and restore.

2. Who it is for

  • Employers and establishment managers who file their own monthly ESIC contribution.
  • Payroll, accounts and HR teams who prepare the monthly file for one or several establishments.
  • Compliance consultants who want a quick, transparent check of a client's data before filing.

4. How to use the tool

  1. Open the tool. On the first visit it asks where your data should be saved. In Chrome or Edge on a computer, choose a dedicated file; the tool then saves to it automatically. Otherwise choose Not now and use Download backup regularly.
  2. Create ESIC file tab, step 1: select the wage month, and enter the establishment name if you wish. The name is only for your own reference.
  3. Download the blank input template, fill the ESI Data sheet with one row per insured person, and import it. You can also add employees one by one, or load the sample rows to see how the tool works.
  4. Review the rows. Check the payable days, gross wages and employee status. For a person with nil days and nil wages, choose the status and enter the last working day if the status requires one.
  5. Click Validate entries. Correct every error. Read each warning and decide whether it applies.
  6. Check the live totals and the contribution for each person.
  7. Download the ESIC contribution file (.xlsx). Check it against the current file format and instructions on the ESIC employer portal before uploading.
  8. Download report (PDF) for a formatted copy for your records and for sign-off. Tick Show full IP numbers and names first if you want them printed in full.
  9. Data tab: download a backup after major changes. When the month is finished, use Clear uploaded data before starting the next month.

5. How the figures are worked out

  • Employer share: 3.25 per cent of gross wages, rounded upward to the next rupee. The total is calculated on total wages, then rounded upward.
  • Employee share: 0.75 per cent of gross wages, rounded upward to the next rupee, for each person.
  • Average daily wages: gross wages divided by payable days. If this is Rs. 176 or less, the employee share is nil. The employer share is still payable.
  • A person with nil payable days has no average daily wage. The tool still calculates the shares on any wages shown.
  • Output: payable days are rounded up to a whole number. The reason code is written only when days are nil. The last working day is written only when days are nil and the status requires it.
  • The tool estimates average daily wages from the gross wages and payable days you enter. Confirm the prescribed calculation and the wages and days that count for each person before filing.

6. Saving, backup and privacy

  • Everything runs in your browser. Your data is not sent to any server by this tool.
  • In Chrome or Edge on a computer, choose a save location the first time. The tool then writes to that file automatically and loads it again next time. The browser may ask once to renew permission.
  • Other browsers keep the data in browser storage only. Use Download backup and Upload backup.
  • Backup and save files contain IP numbers and names. Keep them in a secure folder and do not share them.
  • The backup text box on the Data tab shows the full backup, including IP numbers and names, because it is meant to be copied. Do not leave it open on a shared screen.
  • Clearing browser data, or using a private window, removes the browser copy. The chosen save file and your downloaded backups are not affected.

7. Known limits

  • This is an independent utility and not an ESIC product or portal. The file layout and instructions must be checked on the ESIC employer portal before every filing.
  • Coverage rules, the wage ceiling, contribution periods, arrears and newly covered employees are not modelled beyond the warning for wages above Rs. 21,000.
  • Masking hides IP numbers and names on the screen only. The Excel file, exports, backups and saved data contain the full values.
  • Browsers without the File System Access API cannot save to a chosen file.

Frequently asked questions

What does the ESIC Monthly Contribution Creator do?

It calculates the ESIC employee share (0.75 per cent) and employer share (3.25 per cent) for each insured person, validates the monthly data, and creates an Excel file in the common ESIC monthly contribution file structure for review before filing.

How is the Rs. 176 average daily wage exemption handled?

Where average daily wages (gross wages divided by payable days) are Rs. 176 or less, the employee share is set to nil. The employer share remains payable. Always confirm the prescribed calculation for each case.

How are the contributions rounded?

Both the employee and employer shares are rounded upward to the next rupee.

Is this an official ESIC tool?

No. It is an independent utility from Techmin HR Solutions. Check the output against the current file format and instructions on the ESIC employer portal before filing.

Is my employee data uploaded anywhere?

No. Files are processed in your browser. Data is kept in browser storage and, in Chrome or Edge, can be saved automatically to a file you choose the first time. Nothing is sent to a server by this tool.

How do I save and restore my work?

Choose a save location when the tool first asks, or use Download backup and Upload backup on the Data and backup tab. The tool restores your rows, wage month and establishment name.

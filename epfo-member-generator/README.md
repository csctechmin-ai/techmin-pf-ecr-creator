# Techmin HR Solutions - EPFO Member Registration Bulk File Generator

A free, browser-only tool that prepares the `#~#` delimited text file for the EPFO member registration bulk upload (30 fields, EPFO reference order).

- No server, no sign-in, no tracking, no external requests. Data is kept in your browser (IndexedDB).
- Enter members one by one or import Excel, JSON or an EPFO TXT file. Fix errors in the Validation Centre. Generate `EPFO_Member_Registration_Bulk_YYYYMMDD.txt`.
- Back up and restore (plain or password-encrypted). Works offline after the first visit.

Folders: `templates/` (import templates in xlsx, json, txt) and `samples/` (invented sample data).

Verify before uploading: the Yes/No convention in the bulk file (default follows the portal form: Y / Yes / blank). Change it in Settings if the portal needs another form.

This is an independent working aid. It is not an EPFO product. Check the current EPFO instructions before uploading. Always keep a copy of your source data.

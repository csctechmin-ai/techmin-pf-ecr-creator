EPFO Member Registration Bulk File Generator

Prepare the EPFO new-member registration bulk file. Add employees one by one or import them from Excel, JSON or an EPFO TXT file. The tool validates every record, including Aadhaar, PAN, IFSC, dates, international worker and differently abled details, and downloads the 30-field TXT file with the #~# delimiter. It works offline, saves your work in your browser, and never uploads employee data.

How to create the EPFO member registration bulk file

  1. Add members in the form, or import an Excel, JSON or EPFO TXT file (templates and a sample file are provided).
  2. Open the Validation Centre and fix every red error. Amber warnings can be reviewed.
  3. Open Generate EPFO TXT, choose the records and download EPFO_Member_Registration_Bulk_YYYYMMDD.txt.
  4. Upload the file on the EPFO portal yourself after checking it.

Questions

What is the EPFO member registration bulk file format?

A plain UTF-8 text file with a header line of 30 field names and then one line per member. Each line has exactly 30 fields separated by #~#, in this order: UAN, prvMemberId, memberName, DOB, DOJ, Gender, fatherHusbandName, relation, mobileNo, emailId, nationality, epfWages, qualification, maritalStatus, isInternationalWorker, countryOfOrigin, passportNumber, passportValidFrom, passportValidTill, isPhisicalHandicap, locomotive, hearing, visual, BankAccNo, Ifsc, NameAsPerBank, PAN, NameAsPerPan, AadhaarNo, NameAsPerAadhaar.

How are Yes and No fields written in the file?

International worker, Differently abled, Locomotive, Hearing and Visual are written as Yes or No by default. Settings lets you choose Y/N, 1/0 or True/False instead.

Can it handle international workers?

Yes. Tick International worker to enter the country of origin (189 EPFO codes), passport number and passport validity dates. The tool checks that the passport is valid and the dates are in order.

Does it check Aadhaar, PAN and IFSC?

Yes. It checks the 12-digit Aadhaar and its check digit, the PAN format, the IFSC format and the bank account number. These are typing checks only; nothing is authenticated with UIDAI, the Income Tax Department or a bank.

Are leading zeroes in UAN and bank account numbers kept?

Yes. UAN, previous member ID, mobile, bank account, PAN and Aadhaar are stored and written as text, so leading zeroes are never dropped.

Is the tool free and does it need a login?

It is free, with no sign-in, no tracking and no external scripts. A voluntary donation is welcome but not required.

Is this an official EPFO tool?

No. It is an independent working aid from Techmin HR Solutions. Check the current EPFO instructions before uploading a file.

How many employees can I add in one file?

Hundreds of records work comfortably. The tool has been tested with 100 sample members and with larger Excel imports. Check the limit set by the EPFO portal for one upload.

What does this tool do?

It prepares the EPFO member registration bulk TXT file. You add or import employees, the tool checks every record, and you download a file with exactly 30 fields per member separated by #~#.

Does it submit the file to EPFO?

No. It is an independent data preparation utility. You upload the generated file yourself on the EPFO portal after checking it.

Where is my employee data stored?

Only in your own browser, in its local database. Nothing is uploaded to Techmin or anyone else, and the tool works offline.

Can I import from Excel?

Yes. Download the Excel template or use your own sheet and map the columns. .xlsx, .xls and .csv are supported, with a preview and an error report.

Does it remember my work?

Yes. Records are saved automatically in your browser, and the SAVE button saves again at any time. Use Backup & Restore to keep a file copy.

Who must use the UMANG app instead?

As per the EPFO notice, UAN generation through the member registration module is restricted except for international workers and citizens of Nepal and Bhutan. Other new employees should generate their UAN through face authentication in the UMANG app.
